# 模板适配说明

公开仓库不包含真实模板、客户资料或历史业务报告。合成测试文件只用于验证代码，不代表任何真实客户的单据格式。

## 为什么上传后仍可能无法导出

当前生成器不是通用 Word / Excel 排版引擎，只支持已经检查布局、字段映射并绑定 SHA-256 的模板。上传文件只能建立原始文件记录；模板存在不等于格式验收通过。没有合适模板、文件哈希不匹配、版式未支持或关键字段缺失时，系统应阻断导出。

空数据库可以启动网站和使用无需模板的功能，但不会凭空生成声称符合用户格式的单据。

## 新模板接入流程

1. 在本机提供合法使用的原稿，移除历史客户签名、印章、批注、隐藏数据及不应复用的业务内容，保留原始副本。
2. 检查实际文件结构、工作表、合并单元格、公式、打印区域、图片、外部链接、嵌入对象与潜在签章风险。
3. 明确各字段来源、类型、必填规则和可编辑范围，确定产品明细容量及多页处理方式。
4. 为该布局编写专用映射和生成适配，保存审核后的 SHA-256 绑定；卖方名称配置须与审核模板一致。
5. 使用明确标注的 `SYNTHETIC` 合成业务数据验证字段、金额、源行对应关系与失败阻断，并检查生成文件中的签章清除结果。
6. 在实际使用的 Office 环境中逐页检查预览和打印，人工验收后再用于业务草稿。

不得通过取消模板白名单、忽略哈希检查或跳过签章安全审查来接入新文件。模板修改后哈希会变化，应重新检查并适配。

## 本机卖方配置

在 `.env` 中设置 `TRADEFLOW_SELLER_NAME`，并用 JSON 数组设置 `TRADEFLOW_TEMPLATE_SELLER_NAMES`。例如下面仅为合成示例：

```dotenv
TRADEFLOW_SELLER_NAME=SYNTHETIC SELLER
TRADEFLOW_TEMPLATE_SELLER_NAMES='["SYNTHETIC SELLER"]'
```

卖方配置不能替代模板布局、内容和 SHA-256 审核。未配置模板卖方名单时，相关模板检查与制单明确阻断。名单仅用于校验，不会替换模板中的固定卖方抬头或银行信息；必须逐项核对其与本次实际卖方一致。上面的配置仅为合成示例，程序不内置默认允许名单。

## 报关模板

报关类别依据已确认的 HS、品名、材质、等级及杆径范围建立，业务员每类填写一次申报信息，并可以查看原始成员、拆分或重新归类。相同 HS 不代表所有产品均可无条件合并，实际申报内容仍需核对。

类别汇总数量及美元金额；显示单价四位，金额两位。总价独立使用源行金额汇总，不因显示单价舍入而改变。净重、毛重、件数等不能从未经确认的 ERP 字段猜测。

原生 Office 打印版式尚未正式验收。所有导出结果都是待人工审阅的草稿，不会自动签署、发送或提交海关。
